# 电商列表图提示词（横版 · 一个方案一张图 · 1200×640）

你是一位资深电商视觉设计师 + 前端工程师。本文件用于生成**商品列表里的横版条目图**：
顶部通栏居中放方案名，左侧只放**产品实拍图**，右侧用大字列出套餐内容，右下角放「立即购买」。
整体追求**干净、留白、大字**，让中老年果农一眼看清「有什么、多少袋、多少钱」，不堆色块、不做花哨装饰。
**左侧不要放 800×800 首图**——首图里已经有方案名、价格、单品和袋数，会和右侧文字重复，并把字号压小。

---

## 一、硬性要求（不得违反）

1. 尺寸 **1200×640 px**，主体用 `<div class="card pkg lst v-hot"> … </div>` 包裹。
2. **只输出** `<body>` 内的 `.card.pkg.lst` 结构，不要输出 `<html>`、`<head>`、`<style>`、`<link>`，不要用 Markdown 代码块标记，直接输出 HTML。
3. **不写 `<style>` 标签，不写内联 `style` 属性**，只能使用「四、类名清单」中的类名。
4. 左侧只放**产品实拍图**（`assets/` 下的单品图，白底），按方案单品数量排布：3 类居中一排、4 类「上 2 下 2」、5 类「上 2 下 3」；每张图**等比缩放、不得裁切、不得拉伸**，最多只保留产品原包装上的印刷字，**不额外加品名、数量、价格**。
5. 右侧只放**纯文字**：单品清单、价格、按钮。**不加底色块、不加边框卡片、不加序号圆圈、不加阴影**；单品之间只用一条 1px 浅灰分割线。
6. **赠品**：在品名后用一个小号红色描边标签「赠品」，数量写「赠 N袋」，该行文字用红色区分；不加黄底、不加整行色块。
7. 数字、单位、规格必须与「五、本次方案」完全一致（如 `20-20-20`、`×3袋`、`580`）。
8. **字体必须使用开源思源黑体**：`Source Han Sans CN`（回退 `Noto Sans SC` / `Noto Sans CJK SC`）。**禁止**使用苹方（PingFang SC）、微软雅黑等未授权商用字体，避免字体侵权。
9. **每张图必须自成一张卡片**：最外层 16px 浅灰底 `#E9EBEF`，内部白色圆角卡片（1px 边框）。多张图上下堆叠时，靠这 32px 浅灰带互相分隔，不能糊成一片。

## 二、视觉规范（固定不变）

| 项 | 约定 |
|---|---|
| 外层底色 | 浅灰 `#E9EBEF`，四周 16px，形成卡片间分隔带 |
| 卡片 | 纯白 `#fff`，圆角 18px，1px 边框 `#DDE1E7` |
| 主文字 | 深墨 `#1F2430` / `#20242E` |
| 次要文字 | 灰 `#6B7280` |
| 分割线 | `#ECECEC` 1px，用于单品清单行与卡片头部下沿 |
| 强调色 | 大红 `#E60023`：方案名里的价格数字、赠品行、价格、购买按钮 |
| 按钮 | 纯色大红矩形 `330×88`，白字 `38px`，圆角 12px，置于**右下角**，下沿与左图下沿齐平 |
| 左图区 | 产品实拍图组，宽 500px（含 12px 内边距），与右栏同高；浅灰面板 `#FAFBFC` + 1px 边框 `#E6E8EC`，圆角 14px；无文字、无阴影 |
| 字体 | 思源黑体 `Source Han Sans CN`（回退 `Noto Sans SC` / `Noto Sans CJK SC`） |
| 字号 | 方案名 38px（居中）/ 副标题 20px / 清单 32px / 价格 66px / 按钮 38px |

> 本图不承担「刺激冲动」的职责，只承担「清晰罗列 + 一键购买」。任何装饰性元素（彩色行卡、圆标、角标、渐变色块）一律不要。

## 三、版面结构（固定骨架）

```
┌──────────────────────────────────────────────────────────────┐
│ 16px 浅灰外框                                                 │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │            早中熟桃树580水溶肥方案  38px 居中            │ │
│ │            全生育期营养 · 一套到位  20px 灰              │ │
│ ├──────────────────────────────────────────────────────────┤ │
│ │ ┌────┐ ┌────┐ ┌────┐   20-20-20水溶肥          ×3袋      │ │
│ │ │产品│ │产品│ │产品│   ─────────────────────────────     │ │
│ │ │图  │ │图  │ │图  │   中量元素钙镁肥           ×1袋      │ │
│ │ └────┘ └────┘ └────┘   ─────────────────────────────     │ │
│ │                       丸壮〔赠品〕              赠 1袋     │ │
│ │                                                          │ │
│ │                       ￥580            ┌──────────┐      │ │
│ │                       整套价           │ 立即购买 │      │ │
│ └──────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

- 方案名与副标题**在卡片顶部通栏居中**，与左右两栏完全分离
- 左侧**只放产品图**，按数量排：3 类居中一排、4 类「上 2 下 2」、5 类「上 2 下 3」（上排居中）
- 左图区与右栏同高：上边对齐、下边对齐
- 左图区宽 500px，与右栏间距 32px；卡片内边距 20px（上下）/ 28px（左右）
- 左图区用**浅色面板框出**：`#FAFBFC` 底 + 1px `#E6E8EC` 边框 + 14px 圆角 + 12px 内边距，让「图区」与右侧文字栏形成两块清晰分区；面板不跨到右栏
- 价格（上）与原价/立省说明（下）分两行，按钮在右，三者底部对齐
- 单品行数可变（2–6 行都适用），行高自动，无需改类名

## 四、类名清单（固定，不得新增）

| 类名 | 用途 |
|---|---|
| `card pkg lst` | 1200×640 容器（`pkg` 仅用于继承配色变量） |
| `v-hot` | 配色方案，固定使用 |
| `lst-card` | 白色圆角卡片（浅灰外框之内） |
| `lst-hd` | 顶部通栏：方案名 + 副标题（居中） |
| `lst-title` | 方案名（`b` 包裹价格数字，红色） |
| `lst-sub` | 副标题 |
| `lst-body` | 左右两栏容器（上边、下边对齐） |
| `lst-goods` | 左侧产品图组容器（宽 500px） |
| `g3` `g4` `g5` | 产品图数量类名：3 类居中一排 / 4 类「上 2 下 2」/ 5 类「上 2 下 3」 |
| `gd` | 单个产品图格 |
| `lst-info` | 右侧文字栏 |
| `lst-list` | 清单容器 |
| `lst-row` | 单行清单（细分割线） |
| `t` | 品名 |
| `q` | 数量（×N袋 / 赠 N袋） |
| `tag` | 品名后的「赠品」小标签 |
| `gift` | 赠品行（整行文字变红） |
| `lst-foot` | 底部基线：价格 + 按钮 |
| `lst-price` | 价格 |
| `u` | 货币单位 ￥ |
| `tip` | 价格后的说明（如「整套价」） |
| `lst-buy` | 右下角「立即购买」按钮 |

**配套样式**：`css/list.css`（列表图专用，不改动 `css/pkg.css` 的首图布局）。HTML 放在 `pages/`，相对路径加一层 `../`：

```html
<link rel="stylesheet" href="../css/styles.css">
<link rel="stylesheet" href="../css/pkg.css">
<link rel="stylesheet" href="../css/list.css">
```

## 六、一致性规则（换方案时）

1. **只改「五、本次方案」**；骨架、类名、字号、留白一律不动。
2. 左图必须与当前方案对应，先出 800×800 首图，再出列表图；不得复用其他方案的图。
3. 品名用**短名**（去掉「汇聚兴农」前缀，保留含量规格），确保 28px 一行放得下。
4. 清单行数随意增减，不加序号、不加底色；赠品行只加 `gift` 类与「赠品」标签。
5. 价格就是实收价。**有真实原价与立省时**，在价格后用小号灰字「原价 ￥X · 立省 Y 元」标注；无折扣方案不写，**不得虚构原价**。
6. **字体一律思源黑体**，禁止苹方、微软雅黑等未授权字体。
7. 输出前自检：① 1200×640；② 左图产品等比缩放、未变形未裁切，数量类名与单品数一致（3→`g3`、4→`g4`、5→`g5`）；③ 右侧只有文字与一条按钮；④ 外层 16px 浅灰外框、内部白色圆角卡片；⑤ 数字与「五」一致；⑥ 赠品行有「赠品」标签且数量为「赠 N袋」；⑦ 左图区上下边与右侧清单/按钮对齐；⑧ 左图产品全部落在浅灰面板内，无一张溢出或被裁切。

## 附：跑图命令

HTML 源文件统一放在 `pages/`（如 `pages/列表-580早中熟桃树水溶肥方案.html`），然后：

```bash
node shot.js pages/列表-580早中熟桃树水溶肥方案.html output 列表-580 1200 640
```

输出 `output/列表-580-1.png`。多个方案用不同前缀（`列表-730` 等），避免覆盖。
