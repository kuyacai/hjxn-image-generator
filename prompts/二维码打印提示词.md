# 二维码打印提示词（竖版工卡 · A4 · 54×85mm · 一页 9 张）

你是一位懂印刷排版的前端工程师。本文件用于把**一枚二维码 + 一行说明文字**排成 A4 可打印文档：
打印后沿每张卡四周的虚线下刀，得到 54×85mm 的竖版小卡，直接插入工卡套使用。
**以后换二维码、换文字，只改「五、本次参数」那几行，其余一律不动。**

---

## 一、硬性要求（不得违反）

1. 纸张 **A4 纵向 210×297mm**，一页排 **3 列 × 3 行 = 9 张**，单张 **54×85mm（竖版）**，单元间距 6mm，整版居中。
2. A4 纸面用 `.qr-sheet` 固定 `210mm × 297mm`，**用 mm 作单位**，禁止用 px 拼版面（打印必须 1mm = 1mm）。
3. 只输出 `<body>` 内的 `.qr-sheet` 结构，不输出 `<html>`、`<head>`、`<style>`、`<link>`，不用 Markdown 代码块标记。
4. **不写 `<style>`、不写内联 `style` 属性**，只能使用「四、类名清单」里的类名。
5. 二维码**等比缩放、不裁切、不拉伸、不加圆角、不加边框、不加阴影**，四周保留至少 4mm 白边（静区），否则会扫不出。
6. 说明文字必须在二维码**正下方水平居中**，字号 **11pt**、加粗、深墨色 `#111`，**不换行**。
7. 每张卡四周用 **0.25pt 浅灰虚线** `#C9CFD9` 标出裁剪线；虚线不能压在二维码上（二维码两侧各留 4mm）。
8. **字体必须使用开源思源黑体**：`Source Han Sans CN`（回退 `Noto Sans SC` / `Noto Sans CJK SC`）。**禁止**苹方（PingFang SC）、微软雅黑等未授权商用字体。
9. 二维码原始带彩色（如绿色小程序标）时**保留原色**，不转灰度。

## 二、视觉规范（固定不变）

| 项 | 约定 |
|---|---|
| 纸张 | A4 纵向 210×297mm，页边距 0 |
| 整版排布 | 3 列 × 3 行，单元 54×85mm，横纵间距均 6mm |
| 左右留白 | (210 − 3×54 − 2×6) / 2 = 18mm |
| 上下留白 | (297 − 3×85 − 2×6) / 2 = 15mm |
| 单张卡 | 纯白 `#fff`，无圆角、无底色、无阴影 |
| 二维码 | 46×46mm，水平居中；卡内上下居中后距上下沿各约 15mm |
| 说明文字 | 11pt 加粗，`#111`，距二维码底边 4mm，居中不换行 |
| 裁剪线 | 0.25pt 虚线 `#C9CFD9`，沿卡片外沿 |
| 字体 | 思源黑体 `Source Han Sans CN` |
| 背景图形 | 打印时必须开启，否则虚线不输出 |

> 本文件只做「清晰可扫 + 好裁剪」，不加标题、不加公司名、不加装饰框、不加页码。

## 四、类名清单（固定，不得新增）

| 类名 | 用途 |
|---|---|
| `qr-sheet` | A4 纸面容器（210×297mm，3×3 网格） |
| `qr-cell` | 单张 54×85mm 工卡内页（自带裁剪虚线） |
| `qr-code` | 二维码图片（46×46mm） |
| `qr-cap` | 二维码下方的说明文字 |

**配套样式**：`css/qr-print.css`（打印专用，独立文件，不并入 `styles.css`）。HTML 放在 `pages/`，相对路径加一层 `../`：

```html
<link rel="stylesheet" href="../css/qr-print.css">
```

## 六、打印与裁剪

1. 打印设置：纸张 **A4**、缩放 **实际大小 / 100%**（**不要**选「适应页面」）、页边距 **无**、**勾选打印背景图形**。
2. 用裁纸刀沿每张卡四周的**虚线内侧**下刀，不要裁进二维码的白边。
3. 建议彩色打印：二维码中心的蓝色 logo 与右下角绿色小程序标都依赖色彩识别。
4. 裁好后先扫码验证 1 张，再批量裁剪。
5. 若工卡套是横版（85×54mm），把参数改成横版并在 `css/qr-print.css` 中改为 `2 列 × 5 行`、单张 `85×54mm`。

## 八、输出前自检

1. 页面物理尺寸 = **210×297mm**（PDF MediaBox 约 595×842pt），**1 页**。
2. 卡片数 = **9**，每张 **54×85mm**，横向 3 列、纵向 3 行，左右留 18mm、上下留 15mm。
3. 二维码 **46×46mm**、等比、未裁切，四周白边 ≥ 4mm。
4. 说明文字 11pt 加粗、思源黑体、居中、不换行、内容与「五」完全一致。
5. 裁剪虚线为 0.25pt 浅灰，虚线不压码。
6. PDF 已内嵌字体（不应出现其他系统字体的替代字形）。
