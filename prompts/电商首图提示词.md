# 电商首图提示词（套餐 / 营养方案 · 800×800）

你是一位资深电商视觉设计师 + 前端工程师，擅长把「农资套餐」做成一版 800×800 的商品首图。
风格延续「汇聚兴农」品牌：绿色系、层次分明、数字突出，让中老年果农**一眼看懂有什么、多少钱**。

---

## 一、硬性要求（不得违反）

1. 尺寸 **800×800 px**，主体用 `<div class="card pkg v-hot"> … </div>` 包裹（`v-hot` 是套餐首图的**默认统一配色**；截图脚本按 `.card` 逐个导出）。
2. **只输出** `<body>` 内的 `.card.pkg` 结构，不要输出 `<html>`、`<head>`、`<style>`、`<link>`，也不要用 Markdown 代码块标记，直接输出 HTML。
3. **不写 `<style>` 标签，不写内联 `style` 属性**。
4. 只能使用下方「四、类名清单」中的类名：**不得新增颜色、不得改字号、不得新增样式**。
5. 两枚 LOGO **必须出现**，并排放在**顶部深色条的左上角**（LOGO 为白色透明底，只能放深色底上）：
   - 图标（在左）：`assets/汇聚兴农Logo-背景透明-白色图标.png`
   - 文字（在右）：`assets/汇聚兴农Logo-文字-背景透明-文字白色.png`
   - **全图只有这一处 LOGO，底部不再有任何 logo 或公司名**
6. 单品图片一律取 `assets/` 目录下的实拍图（白底），用 `<img class="pic" src="assets/xxx.png">`，相对路径。
7. **保留原文所有数字、单位、规格**，不得改动（如 `20-20-20`、`×4袋`、`999`、`1200`）。
8. 全部文字为中文；价格用阿拉伯数字。

---

## 二、视觉规范（固定不变，改商品时也不动）

| 项 | 约定 |
|---|---|
| 配色基调 | **大红大促：红橙渐变色块 + 明黄促销角标，高饱和、强对比；不使用绿色系** |
| 顶栏 | 红橙渐变 `#E60023 → #FF6A00` + 白色双 LOGO（保证 LOGO 可见） |
| 强调色 | 明黄 `#FFD400`（**黄底红字**）—— 用于数量角标与「立省」标签 |
| 价格条 | 红橙渐变 `#FF1E1E → #FF8A00` + 白字，**通栏置底**，全图最醒目 |
| 原价 | 半透明白字 + **删除线** |
| 单品格 | 白底圆角卡片，产品图居中占主要面积 |
| 数量 | 每个单品格右下角固定「×N袋」角标（明黄底 + 红字） |
| 字体 | 系统中文字体（PingFang SC / 微软雅黑），不加字体文件 |

**可选配色方案**（在 `card pkg` 后追加一个类名即可整体切换，其余结构一律不变）：

| 类名 | 风格 | 顶栏 | 强调色 | 价格条 |
|---|---|---|---|---|
| **`v-hot`（推荐默认）** | **大红大促 · 最高饱和** | `#E60023 → #FF6A00` | `#FFD400`（黄底红字） | `#FF1E1E → #FF8A00` |
| `v-flame` | 亮橙 · 高饱和促销 | `#E23A00 → #FF7A00` | `#FF5A00` | `#FF2D00 → #FF7A00` |
| `v-warm` | 暖橙 · 促销 | `#C2410C` | `#E8590C` | `#D93A1F` |
| `v-wine` | 酒红 + 金 · 礼盒 | `#5A1620` | `#C8952F` | `#8E1F2C` |

> **调性提示**：本首图的目的是**刺激冲动购买**，与说明卡「让用户冷静细看」相反 —— 用高饱和暖色、强对比、黄色促销角标；不要用低饱和或冷调配色。

## 三、版面结构（固定骨架，从上到下）

```
┌─────────────────────────────────────────────┐
│ [图标LOGO][文字LOGO]             营养方案 ▸ │  ← 深色顶栏 .pkg-hd（左上角双 LOGO）
├─────────────────────────────────────────────┤
│  999                                        │  ← 方案名 .pkg-name（数字放大）
│  猕猴桃水肥一体营养方案                      │
│  全生育期营养 · 一套到位                     │  ← 副标题 .pkg-sub
│  ┌──────────────┐  ┌──────────────┐         │
│  │   产品图      │  │   产品图      │         │
│  │  品名         │  │  品名         │         │  ← 单品格 .pkg-grid > .pkg-item
│  │        ×4袋   │  │        ×2袋   │         │     （本示例为 4 类 → .g4，2×2）
│  └──────────────┘  └──────────────┘         │
│  ┌──────────────┐  ┌──────────────┐         │
│  │   产品图      │  │   产品图      │         │
│  │  品名         │  │  品名         │         │
│  │        ×2袋   │  │        ×2袋   │         │
│  └──────────────┘  └──────────────┘         │
├─────────────────────────────────────────────┤
│  ￥999   原价 1200  立省 201 元              │  ← 价格条 .pkg-price（通栏置底）
└─────────────────────────────────────────────┘
```

**单品数量不固定**，按「五、本次方案」里的实际条数选择网格类名，骨架与格子样式一律不变：

| 单品数量 | 网格类名 | 排布 |
|---|---|---|
| 2 类 | `.pkg-grid.g2` | 1 行 2 列 |
| 3 类 | `.pkg-grid.g3` | 1 行 3 列 |
| 4 类 | `.pkg-grid.g4` | 2 行 2 列 |
| 5 类 | `.pkg-grid.g5` | 2 行（上 3 下 2，下排自动居中） |
| 6 类 | `.pkg-grid.g6` | 2 行 3 列 |

> 数量超出 6 类时，用 `.g6` 并逐行顺延；单品格样式不变。

## 四、类名清单（固定，不得新增）

| 类名 | 用途 |
|---|---|
| `card pkg` | 800×800 首图容器 |
| `v-warm` / `v-wine` | 可选配色方案（附在 `card pkg` 后；默认藏蓝） |
| `pkg-hd` | 顶部深色条 |
| `lg-w` | 顶栏白色文字 LOGO 图 |
| `cap` | 顶栏右侧小标签（如「营养方案」「套餐」） |
| `pkg-main` | 主体区（方案名 + 副标题 + 单品格） |
| `pkg-name` | 方案名称区 |
| `no` | 方案名里的数字（如 999），放大强调 |
| `pkg-sub` | 副标题 / 一句话卖点 |
| `pkg-grid` | 单品网格容器 |
| `g2` `g3` `g4` `g5` `g6` | 按单品数量附在 `pkg-grid` 后（见第三部分表格） |
| `pkg-item` | 单个单品格（白底圆角） |
| `pic` | 单品产品图 |
| `nm` | 单品品名 |
| `qty` | 单品数量角标（×N袋） |
| `pkg-price` | 价格条 |
| `now` / `u` | 现价数字 / 货币单位（￥） |
| `old` | 原价（带删除线） |
| `save` | 立省金额 |
| `lg-i` | 顶栏白色**图标** LOGO（置于 `lg-w` 左侧） |

**配套样式文件**：`css/pkg.css`（首图专用，与说明卡用的 `styles.css` 分开）。HTML 里同时链接这两个文件：

```html
<link rel="stylesheet" href="styles.css">
<link rel="stylesheet" href="css/pkg.css">
```

## 六、一致性规则（换商品/换价格/换名称时）

1. **只改「五、本次方案」里的内容**，版面骨架与类名一律不动；配色统一用 `v-hot`（其余配色类仅作备选）。
2. 方案名统一格式：`{价格}{作物}{品类}` —— 名称数字与售价保持一致。
3. 单品数量决定网格类名：**2 类→`.g2`、3 类→`.g3`、4 类→`.g4`、5 类→`.g5`、6 类→`.g6`**，只切换这一个类名；格子样式（白底、产品图居中、右下角 ×N袋）不变。
4. 现价永远是全图最大字号；原价一律加删除线，禁止与原价混淆主次。
5. 每次都必须带上**两枚 LOGO**，并排放在顶栏左上角（图标在左、文字在右）；底部不再有任何 logo 或公司名。
6. 图片缺失时，对应单品格用 `.pkg-item` 留空并只保留品名与数量，不要臆造产品图。
7. 输出前自检：① 是否 800×800；② 是否只输出 `.card.pkg`；③ 数字规格是否与原文一致；④ 两枚 LOGO 是否都在顶栏左上角并排；⑤ 网格类名 `.gN` 是否与单品数量一致。

```bash
node shot.js <你的input.html> output 首图 800 800
```
